# Continual Recognition of Printed Polymer Contexts from Published Average Mechanical Records

This review branch provides the computational materials prepared for manuscript A v25 by **Salih Çolakoğlu and Mustafa Onat**, Marmara University.

[Open the complete computational package](A_v25/README.md): MATLAB code, attributed data, saved results and model states, Simulink inference demonstrations, eight figures, plotting sources, licenses, and reproduction instructions. The package retains both learning settings, both development partitions, and all five initialization seeds.

Start with [the saved summary tables](A_v25/07_Sonuclar/learning_run_v1/summary_v1/), [the source data description](A_v25/DATA_SOURCES.json), and [the reproduction guide](A_v25/REPRODUCIBILITY.md). Simulink applies the saved classifiers; learning occurred in MATLAB. The Python summary CLI requires Matplotlib for its plotting stage; the saved tables and accepted MATLAB plots can be inspected directly.

The files are available for scientific review. **A v25.0 version-specific release and Zenodo DOI remain pending.** Cite a verified commit from this branch to identify these materials until the version archive is available. The [v23.0 release](https://github.com/salihcolakoglu/printed-polymer-continual-recognition/releases/tag/v23.0) and [DOI 10.5281/zenodo.23289833](https://doi.org/10.5281/zenodo.23289833) identify the earlier computational files only.

Original data: [Mendeley Data version 2](https://doi.org/10.17632/zd6td6svd6.2), with the associated [Micromachines article](https://doi.org/10.3390/mi17070859). The method adaptation's sources are retained in [METHOD_PROVENANCE.md](A_v25/METHOD_PROVENANCE.md).
