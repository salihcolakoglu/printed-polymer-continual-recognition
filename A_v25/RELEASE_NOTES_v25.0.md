# v25.0 — MATLAB, Simulink, data, results, and figures

Release draft for computational materials supporting “Continual Recognition of Printed Polymer Contexts from Published Average Mechanical Records” by Salih Çolakoğlu and Mustafa Onat, Marmara University.

The package combines the preserved reference comparisons with task-incremental and class-incremental experiments using ordinary and Walsh codes, negotiated targets, replay, and joint-seen controls. It supplies the attributed cohort of 104 published averages, all five initialization results, saved model states, two Simulink inference demonstrations, eight figures, plotting sources, and reproduction instructions.

Original code is MIT. Data derivatives, owned figures, scientific documents, results, weights, and authored model artifacts are CC BY 4.0 within the authors' rights. Source-specific conditions and the method repository's MIT notice are retained.

Original dataset: https://doi.org/10.17632/zd6td6svd6.2
Associated source article: https://doi.org/10.3390/mi17070859
