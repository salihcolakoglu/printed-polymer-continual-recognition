# Figure materials

The supplementary ZIP contains a `figures/` folder with all four source CSV tables, MATLAB plotting code, Python data-extraction/formatting helpers and final PNG/PDF/SVG figures. The working release stores them in `02_Sekiller/`. The MATLAB renderer and Python data-only branch were executed in v22. The Python matplotlib drawing branch was not executed in that environment. A v23 preserves those numerical figure materials and supplies the revised captions. See `README_figures.txt` for the source links and captions.
