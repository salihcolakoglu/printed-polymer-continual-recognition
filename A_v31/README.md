A31 computational materials — archive guide

Scope: Printed-polymer context recognition from previously published source-average mechanical records by Salih Çolakoğlu and Mustafa Onat. The materials are exploratory and are not independent specimen-level or production validation. The current manuscript draft and its revision history are maintained separately from these computational materials.

Files:
1. A30_Supplement_S1_v1.zip contains the established two-input group-fold computational package and v30 Simulink bank. It is the same complete asset associated with the previously published v30 release and DOI https://doi.org/10.5281/zenodo.23474663.
2. The A31 computational extension contains printing-input NN1/PROTO comparisons, Walsh and ordinary coding, uncoded negotiated learning, taskwise negotiation-rate comparisons, stored models, predictions, code, figures and earlier verification artifacts. For the complete archive, extract A31_S2_Computational_Extension_v4_public_safe.zip. When using the GitHub repository distribution, instead download all 18 files in A_v31/github_web/, from A31_S2_Web_part01.zip through A31_S2_Web_part18.zip, and extract each into the same empty directory. Both options reconstruct the same A31_v4 directory; the parts are independent ZIP archives, not fragments to concatenate. Each task uses a fixed rate; the three-task increasing profile is 0, 0.5, 1 and the decreasing profile is 1, 0.5, 0.
3. A31_Simulink_Verification_Addendum_v1.zip is essential alongside file 2. It records the later selected desktop MATLAB/Simulink pathway and independent verification of confidence-gap groups and threshold counts across 6,300 stage populations. The old v4 README and NATIVE_SIMULINK_COMPONENT_STATUS_v4.json preserve an earlier two-population difference in the original compiled NL4 route. They are historical descriptions of that route; the later addendum documents the verified desktop NL4 route with a MATLAB helper and the retained compiled OH8/WH8 evidence. Do not read the earlier HOLD as the current status of the later route or mistake the later route for standalone generated code.
4. A31_Supplement_S2_v17.docx and .pdf document the current detailed methods and outcomes. Their statements that this A31 extension was local describe the time the files were prepared. A new DOI must be inserted only after an actual public record exists and should identify that exact published version.
