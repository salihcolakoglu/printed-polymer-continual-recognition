The present implementation uses fixed global OH8/WH8 dictionaries, a shared
small tanh network, frozen stage-start targets and nearest mean-squared-code
decoding. Alpha=[1/2,2/3,3/4]. Replay uses hard original codes for retained
records. These are explicit adaptations, not a rerun of the image notebook.

Replay uses two metadata-hash-selected first-arrival TRAIN parents per class,
a maximum of eight unique parents, current/memory overlap removal, and equal
current/memory mean-loss mass when memory is nonempty. EWC uses separate
anchors and exact diagonal model-expected Fisher; lambda = 10 is primary and
lambda = 1 and 100 are predeclared sensitivities. LwF uses T = 2, lambda = 1, no extra T^2,
and current-input frozen-teacher responses over complete old class masks.
The supplied numerical protocol defines all details and information access.

CE models have 32 parameters and coded models 52. Cross-block differences
compare complete procedures. The OH/Walsh contrast includes bit density and
code geometry and does not isolate orthogonality or establish error correction.
No unpublished earlier paper by the manuscript authors is cited as scientific
authority. Historical component names identify computational files only.
